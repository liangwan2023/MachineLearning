# Cardiovascular Disease Risk Prediction

## Project Overview

This project builds a machine learning workflow to predict cardiovascular disease risk level using structured patient health data.

The goal is to classify a patient's cardiovascular disease risk into one of three categories:

- LOW
- INTERMEDIARY
- HIGH

This project is designed as an applied machine learning workflow using tabular data, preprocessing pipelines, model comparison, evaluation metrics, error analysis, and software integration considerations.

The project is currently implemented in Google Colab.

---

## Problem Statement

Cardiovascular disease risk prediction is an important applied machine learning problem because patient health data often contains structured numeric and categorical information that can be used to support early risk screening.

In this project, the machine learning model uses patient features such as demographic, lifestyle, and clinical indicators to predict cardiovascular disease risk level.

This project should be treated as an educational and applied ML workflow demonstration, not as a clinically validated diagnostic system.
